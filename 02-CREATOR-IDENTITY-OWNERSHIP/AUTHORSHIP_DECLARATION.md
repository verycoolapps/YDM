## DECLARATION PHILOSOPHY

An authorship declaration is a **formal statement of claimed creative origin**. It must be:

1. Specific — identifying the exact work being declared
2. Dated — recording when the declaration was made
3. Attributed — clearly naming the creator and owner
4. Honest — distinguishing what is original from what is derived
5. Caveated — noting its status as a user declaration

It is NOT:
- A legal guarantee of ownership
- A substitute for formal copyright registration
- An automatically enforceable document
- Proof against an infringer who disputes the claim

## DECLARATION VARIANTS

### Short-Form Declaration (Mode B)
For lightweight protection — embed in document headers or file metadata:
```
© [YEAR] [NAME] | YDM-[ID] | Created: [DATE] | All rights declared
```

### Collaboration Declaration
When multiple creators are involved:
```
JOINT AUTHORSHIP DECLARATION
Creators: [NAME 1] + [NAME 2]
Contributions: [NAME 1]: [THEIR ELEMENTS] | [NAME 2]: [THEIR ELEMENTS]
Joint Ownership: [ARRANGEMENT]
```

### Posthumous / Legacy Declaration
For documenting historical creative work retroactively:
```
RETROACTIVE DOCUMENTATION NOTICE
This declaration documents pre-existing work created on approximately
[DATE]. Documentation was initiated retroactively on [CURRENT DATE].
Evidence of original creation: [SOURCES]
Limitations: Retroactive documentation carries lower evidentiary
weight than contemporaneous records.
```
