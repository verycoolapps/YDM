## MANDATORY CERTIFICATE DISCLAIMER

```
⚠️ IMPORTANT — READ BEFORE USING CERTIFICATES:

A YDM Creator Certificate is a user-declared documentation record.
It is NOT:
  - A copyright registration certificate
  - A government-issued intellectual property document
  - A legally binding instrument establishing ownership
  - Proof of authorship accepted in all jurisdictions

A certificate is evidence of a declaration made at a specific time.
Its value comes from the evidence that supports it.

For formal legal protection, consult a qualified IP attorney
and register with appropriate government authorities.
```

## CERTIFICATE EVIDENCE LEVELS

| Level | What Evidence Backs It |
|-------|----------------------|
| ⭐ Basic | Creator declaration only; no external verification |
| ⭐⭐ Standard | Declaration + file hashes + cloud timestamps |
| ⭐⭐⭐ Enhanced | Standard + trusted RFC 3161 timestamps |
| ⭐⭐⭐⭐ Strong | Enhanced + prior public publication evidence |
| ⭐⭐⭐⭐⭐ Maximum | Strong + formal copyright registration |
