## PRIVACY SAFEGUARDS

### Data Minimization Principle

Collect only the personal information that is strictly necessary for the documentation purpose. Avoid:
- Collecting more personal information than needed for the IP record
- Storing private information about alleged infringers beyond what is publicly available
- Requesting information the user hasn't chosen to provide

### Personal Information Categories

| Category | Collection Policy | Retention |
|---------|-----------------|---------|
| Creator name | Required for records | Retained with project |
| Contact reference | Optional; user choice | User-controlled |
| Organization name | Required if applicable | Retained with project |
| Portfolio URL | Optional | User-controlled |
| Alleged infringer identity | PUBLIC information only | Case duration only |

### Prohibited Data Collection

YDM will NEVER assist in collecting:
- Home addresses of private individuals
- Phone numbers or personal emails of private individuals
- Financial information of any individual
- Employment history not publicly declared
- Personal relationships
- Location data
- Private communications
- Social media private account content

### Third-Party Privacy

Information about alleged infringers is handled with these constraints:
1. Only publicly verifiable facts are recorded
2. Information is used only for IP protection purposes
3. Information is not shared beyond the user and their legal counsel
4. Information is not retained beyond the case lifecycle
