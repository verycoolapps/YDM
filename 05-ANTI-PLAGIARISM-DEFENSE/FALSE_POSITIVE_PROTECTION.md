## FALSE POSITIVE PREVENTION

The most dangerous failure mode in plagiarism detection is a **false accusation** — incorrectly accusing someone of copying when no copying occurred.

False accusations can:
- Destroy innocent creators' reputations
- Expose the accuser to defamation liability
- Undermine the entire case by demonstrating poor judgment
- Harm professional relationships permanently

### False Positive Checklist (Run Before ANY Formal Action)

```
FALSE POSITIVE PREVENTION CHECKLIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ 1. GENERIC ELEMENT CHECK
     Are the similarities limited to genre conventions,
     standard techniques, or common design patterns?
     → If yes: similarity likely not actionable

□ 2. INDEPENDENT CREATION CHECK
     Is independent creation plausible?
     → Consider: Was original work public? When?
     → Consider: Is the concept common enough that two people
        could arrive independently?

□ 3. COMMON SOURCE CHECK
     Could both works have drawn from the same third-party source?
     → Search for the alleged "original" idea in earlier works

□ 4. TIMING CHECK
     Is there solid evidence that original predates suspected copy?
     → Weak: "I created this first" (self-reported only)
     → Strong: External timestamps, prior publication

□ 5. SPECIFICITY CHECK
     Are the similarities in genuinely distinctive, non-obvious elements?
     → Color: usually not distinctive enough alone
     → Specific composition + specific element + specific treatment: more distinctive

□ 6. THRESHOLD CHECK
     Does the evidence meet the threshold for the proposed action?
     → Internal note: any evidence
     → Formal notice: moderate-to-strong evidence with distinctive matches
     → Legal action: strong evidence; must consult qualified lawyer

□ 7. ALTERNATIVE EXPLANATION
     Has every innocent explanation been genuinely considered?
     → Document why each is or isn't applicable
```

### Pre-Accusation Minimum Standards

| Action | Minimum Evidence Required |
|--------|--------------------------|
| Internal note | Any similarity noticed |
| Casual mention | Noticeable specific similarity |
| Formal inquiry | Moderate evidence with distinctive matches |
| Formal notice / C&D | Strong evidence with distinctive matches; legal review recommended |
| Platform takedown | Strong evidence; understand consequences of false claims |
| Legal action | Consult qualified IP attorney |
