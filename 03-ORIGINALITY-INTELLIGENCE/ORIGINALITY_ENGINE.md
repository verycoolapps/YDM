## ORIGINALITY FRAMEWORK

### What Copyright Protects
Copyright protects **original expression** — the specific, concrete way an idea is expressed. It does NOT protect:
- Ideas, concepts, themes (the idea-expression dichotomy)
- Facts, data, information
- Methods, processes, systems, procedures
- Common design patterns and conventions
- Generic elements that are standard in a field

### What YDM Analyzes
YDM helps document the **original expressive choices** that make a work distinctively the creator's own:
- Unique combination of elements (even if individual elements are common)
- Specific creative decisions that reflect the author's personality
- Novel arrangements, structures, or compositions
- Original visual, stylistic, or technical signatures

## DISCIPLINE-SPECIFIC ORIGINALITY INDICATORS

### For Software/Code
- Novel algorithm design or implementation approach
- Unique architectural decisions
- Original naming conventions and structure
- Specific logic sequences that aren't industry-standard

### For Visual Art
- Unique color palette and application method
- Specific compositional choices
- Original character design elements
- Distinctive linework, texture, or rendering style

### For Brand Identity
- Unique letterform modifications
- Original symbol/icon design
- Specific color combination and usage rules
- Distinctive visual language system

### For Writing
- Original narrative structure
- Unique voice and tone
- Invented characters, worlds, terminologies
- Specific argumentative framework
